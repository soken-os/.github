## Status

Pre-launch. Private development. Architecture locked V1.4-fixed (May 28, 2026). First vertical slice in flight.

## What's here

- **`soken`** — the monorepo. Python (FastAPI) backend + TypeScript (React) frontend. Phase 1A scope: Tenant + RLS + Tool Registry + Audit foundation; Lead → Estimate → Schedule → Cash Flow Projection vertical slice; Operational + Pipeline projection with confidence floors; Voice (capture + draft only); Authority Matrix with eight seed roles.

## What Sōken is

A multi-tenant platform that ingests estimates, generates schedules, manages subcontractors and clients, and produces continuous forward-looking financial projections that no other tool in the residential construction market provides. Forward financial projection is the differentiated product center: cash flow projection six to seven months forward, validated against accounting truth (QuickBooks / Xero, read-only).

Tenant #1: Carlson Projects (Lincoln, Nebraska). Designed for the second tenant from day one.
